# 네이버 황금키워드 (naver-golden-keywords)

검색량이 많아도 이미 글이 수십만 개 쌓인 키워드는 새 블로그가 상위에 오르기 어렵습니다. 이 스킬은 네이버 공식 API 두 개로 **검색량 대비 문서수(경쟁률)** 를 계산해, 써 볼 만한 키워드를 등급으로 나눕니다.

## 준비 (처음 한 번)
1. **검색광고 API**: [searchad.naver.com](https://searchad.naver.com) 로그인 → 도구 → API 사용 관리에서 API 키, 비밀키, 고객 ID를 발급합니다. 광고비를 쓰지 않아도 발급됩니다.
2. **검색 API**: [developers.naver.com](https://developers.naver.com) → 애플리케이션 등록 → 사용 API에 '검색'을 넣고 Client ID와 Secret을 받습니다.
3. 작업 폴더에 `.env`를 만듭니다(`.env.example` 참고). 이 파일은 깃에 올리지 않습니다.

## 준비물 (쓰기 전에 있어야 하는 것)
| 준비물 | 어디에 쓰나요 | 꼭 필요한가요 |
|---|---|---|
| Node 18 이상 | 스크립트 실행 | 필수 |
| 네이버 검색광고 계정과 API 키 3개 | 월간 검색량 조회(광고비를 쓰지 않아도 발급됩니다) | 필수 |

| 내 블로그 주제와 최근 쓴 글 목록 | 키워드를 고른 뒤 겹치지 않는지 판단 | 권장 |

## 바꿔 쓰기: 이렇게 말하세요
에이전트에게 왼쪽처럼 말하면 오른쪽을 바꿔서 실행합니다.

| 이렇게 말하면 | 바뀌는 것 |
|---|---|
| "검색량이 적어도 경쟁 없는 키워드를 보여 줘" | `--rules S:300:0.2,A:200:1,B:100:3` 처럼 등급 기준을 낮춥니다 |
| "등급 이름을 골드·실버로 해 줘" | `--rules 골드:30000:3,실버:10000:10` |
| "연관 키워드도 같이 30개 봐 줘" | `--related 30` |
| "엑셀로 받고 싶어" | `--csv result.csv` (엑셀에서 한글이 깨지지 않게 저장합니다) |
| "내 후보 목록 파일로 돌려 줘" | `--file seeds.txt` 한 줄에 키워드 하나 |

건강·금융처럼 조심할 단어 목록은 `scripts/golden-keywords.mjs`의 `BLOCK`(제외)과 `CAUTION`(주의)에서 고칩니다.

## 사용
```bash
node scripts/golden-keywords.mjs 캠핑의자 "가을 캠핑 준비물" 전기요
node scripts/golden-keywords.mjs 캠핑의자 --related 20 --csv result.csv   # 연관 키워드 20개까지 함께 채점
node scripts/golden-keywords.mjs --file seeds.txt --json
```

| 등급 | 월간 검색량 | 경쟁률(문서수 ÷ 검색량) |
|---|---|---|
| S | 2,000 이상 | 0.1 이하 |
| A | 1,000 이상 | 0.5 이하 |
| B | 500 이상 | 2 이하 |

## 채택 판단 (에이전트가 할 일)
도구는 후보만 추천합니다. 위에서부터 아래 조건을 모두 통과하는 첫 후보를 씁니다.
1. 네이버에서 직접 검색해 그 키워드가 실제로 무엇을 가리키는지 확인합니다. 브랜드명이나 방송 제목이 섞여 있는 경우가 많습니다.
2. 블로그의 주제와 맞고, 공식 자료나 믿을 만한 출처로 사실을 확인할 수 있어야 합니다.
3. `[제외]` 표시(사건사고·도박·마약 등)는 쓰지 않습니다. `[주의]` 표시(건강 효능·금융·사생활)는 근거 없이 단정하는 글이 되지 않는지 직접 판단합니다.
4. 최근에 쓴 글과 주제·각도가 겹치지 않아야 합니다.

## 글에 넣는 법
- 채택한 키워드를 글의 핵심 주제로 삼고, 제목에 한 번, 도입 1~2문단 안에 한 번 자연스럽게 넣습니다.
- 정확한 형태는 본문 전체에서 3~5회 안쪽으로 두고, 나머지는 자연스러운 표현을 씁니다.
- 검색량이 많은 무관한 단어를 끼워 넣지 않습니다. 네이버 스팸 정책의 키워드 반복·낚시성에 걸립니다.
- 공개 글에 검색량, 등급, 도구 이야기를 쓰지 않습니다.

## 주의
- 검색량은 네이버가 주는 최근 30일 값이고 "< 10"은 5로 계산합니다. 문서수는 조회 시점 값입니다.
- 키 값을 화면이나 로그에 출력하지 않습니다. 스크립트도 출력하지 않습니다.
- 검색광고 API는 짧은 시간에 많이 부르면 429 오류가 나는데, 스크립트가 잠시 쉬었다가 최대 3번 다시 시도합니다.

## 출처와 영감
- **데이터 출처**: 네이버 검색광고 API의 키워드 도구([공식 문서](https://naver.github.io/searchad-apidoc/))와 네이버 개발자센터 검색 API의 블로그 검색([공식 문서](https://developers.naver.com/docs/serviceapi/search/blog/blog.md))만 씁니다. 각 API의 이용 약관과 호출 한도를 따릅니다.
- **"황금키워드"라는 생각**: 검색량에 비해 글이 적은 키워드를 고르는 방식은 국내 블로거들 사이에서 널리 쓰이는 일반적인 방법입니다. S·A·B 등급 기준값은 작성자가 정한 것이고 `--rules`로 바꿀 수 있습니다.
